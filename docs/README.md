# Documentación de D&D Adventures AI

- **[Guía de Inicio Rápido](./inicio-rapido.md)** - Instalación, configuración y visión de diseño del juego.
- **[Arquitectura Técnica](./arquitectura.md)** - Diagramas cliente-servidor, flujo de IA de narración, FSM del motor de combate y persistencia.
- **[Roadmap e Issues Tracker](./roadmap.md)** - Control de fallos (bugs), ideas rápidas de desarrollo y planificación de características futuras.
- **[Manual de Testing y QA](./testing.md)** - Uso de Vitest para pruebas automatizadas, inyección de dependencias (DI) y pautas de QA manual.
- **[Notas de Desarrollo y Frases de Testeo](./notas-desarrollo.md)** - Buzón de entrada de borradores y frases rápidas para interactuar con el narrador en fase de pruebas.
- **[Normas de Trabajo](./normas-de-trabajo.md)** - Ramas, commits, CI obligatoria, documentación y ficheros con tratamiento especial.
